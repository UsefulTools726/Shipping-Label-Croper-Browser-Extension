Privacy Policy

Shipping Label Cropper browser extension

Last updated: October 28, 2026

Data collection

This extension does not collect, transmit, or store any personal data on external servers.

Local storage

The extension stores the following data only on your device using the browser’s local storage:

  • Your auto-crop on/off preference
  • Optional crop templates you create so the extension can recognize similar labels later

This data never leaves your browser.

Permissions

The extension requests permissions only to read the PDF you choose to crop, process it locally, and open the result in a new tab. No data is sent to the developer or any third party.

Contact

If you have questions, open an issue on the GitHub repository.
